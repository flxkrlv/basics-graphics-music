# Picburner EP4CE6E22C8N (минимальная плата Cyclone IV E)

Плата на микросхеме Altera (Intel) Cyclone IV E `EP4CE6E22C8N` (144-pin LQFP,
6272 LE, 50 МГц генератор). Имя конфигурации: `picburner_ep4ce6`.
Тулчейн: Intel Quartus Prime Lite.

Источник распиновки: `boards/picburner_ep4ce6/reference/EP4CE6E22C8N_Picburner_Schematic.pdf`
(схема платы) и таблица периферии (`LED`, `кнопки`, `W25Q`, `CH340C`, `кварц`).
В схеме имена цепей вида `IO<N>` соответствуют номеру пина FPGA `PIN_<N>`.

Все используемые банки ПЛИС запитаны от **3.3 В** (`VCCIO1-2 = 3V3`,
`VCCIO3-5 = VB = 3V3`, `VCCIO6-8 = VC = 3V3`). Для всех сигналов
используется `3.3-V LVTTL`.

Комментарии с полной распиновкой заголовков также есть в
[`board_specific_top.sv`](./board_specific_top.sv), назначения пинов — в
[`board_specific.qsf`](./board_specific.qsf).

> **Перед первым подключением** проверьте номера пинов разъёмов P2/P3/P4
> по схеме или мультиметром (прозвонкой до ПЛИС). Таблицы ниже составлены
> по схеме.

## Что есть на плате (поддерживается без доп. модулей)

| Элемент | Пин ПЛИС | Примечание |
|---|---|---|
| Генератор 50 МГц | `PIN_24` | тактирование (`CLK`) |
| Кнопка K3 (RESET) | `PIN_88` | активный низкий уровень, подтяжка 3.3 В |
| Кнопка K1 | `PIN_114` | `KEY_SW[0]`, активный низкий |
| Кнопка K2 | `PIN_89` | `KEY_SW[1]`, активный низкий |
| Кнопка K4 | `PIN_80` | `KEY_SW[2]`, активный низкий |
| Кнопка K5 | `PIN_73` | `KEY_SW[3]`, активный низкий |
| Светодиод DL1 | `PIN_1` | `LED[0]`, **активный низкий** (0 = горит) |
| Светодиод DL2 | `PIN_2` | `LED[1]`, активный низкий |
| Светодиод DL3 | `PIN_3` | `LED[2]`, активный низкий |
| Светодиод DL4 | `PIN_7` | `LED[3]`, активный низкий |
| Светодиод DL5 | `PIN_11` | `LED[4]`, активный низкий |
| USB-UART CH340C | TX `PIN_10`, RX `PIN_23` | через USB-порт, отдельного подключения не требуется |
| SPI-флеш W25Q64 | CS 87, MISO 84, MOSI 74, SCK 75 | зарезервировано, в лабах не используется |

Вся **внешняя** периферия подключается к разъёмам **P2, P3, P4**.

## Что подключать и куда

Номера разъёмов — из схемы. Левая колонка разъёма — нечётные контакты,
правая — чётные.

### 1. TM1638 (LED и кнопки, модуль 5 проводов)

| Сигнал TM1638 | Разъём | Пин ПЛИС | Имя в коде |
|---|---|---|---|
| VCC | P3 контакт 37 или 38 (3V3) | — | — |
| GND | P2 контакт 21 или 23 (GND) | — | — |
| STB | P2 контакт 14 | IO28 (`PIN_28`) | `TM_STB` |
| CLK | P2 контакт 15 | IO30 (`PIN_30`) | `TM_CLK` |
| DIO | P2 контакт 19 | IO34 (`PIN_34`) | `TM_DIO` |

Включение: `INSTANTIATE_TM1638_BOARD_CONTROLLER_MODULE` (как в лабах с TM1638).

### 2. Микрофон INMP441 (I2S, данные от микрофона в ПЛИС)

| Сигнал INMP441 | Разъём | Пин ПЛИС | Имя в коде |
|---|---|---|---|
| VDD | P3 контакт 37 или 38 (3V3) | — | — |
| GND | P3 контакт 45 или 46 (GND) | — | — |
| L/R | P4 контакт 9 | IO39 (`PIN_39`) | `MIC_LR` (ПЛИС выдаёт 0 = левый канал) |
| WS | P4 контакт 11 | IO43 (`PIN_43`) | `MIC_WS` |
| SCK | P4 контакт 13 | IO46 (`PIN_46`) | `MIC_SCK` |
| SD | P4 контакт 15 | IO50 (`PIN_50`) | `MIC_SD` |

Включение: `INSTANTIATE_MICROPHONE_INTERFACE_MODULE`.

### 3. Аудио ЦАП PCM5102 (I2S, данные из ПЛИС в ЦАП)

| Сигнал PCM5102 | Разъём / подключение | Пин ПЛИС | Имя в коде |
|---|---|---|---|
| VIN | 3V3 (P3 контакт 37 или 38) | — | — |
| GND | GND (P3 контакт 45 или 46) | — | — |
| BCK | P4 контакт 10 | IO38 (`PIN_38`) | `DAC_BCK` |
| LCK (LRCK) | P4 контакт 12 | IO42 (`PIN_42`) | `DAC_LRCK` |
| DIN | P4 контакт 14 | IO44 (`PIN_44`) | `DAC_DIN` |
| SCK | GND | — | (MCLK не используется) |
| FLT | GND | — | обычная задержка фильтра |
| DEMP | GND | — | деэмфазис выключен |
| XSMT | 3V3 | — | снят мьют |
| OUTL / OUTR | наушники или усилитель | — | подключает пользователь |

Включение: `INSTANTIATE_SOUND_OUTPUT_INTERFACE_MODULE`.

Примечание: PCM5102 работает без MCLK, если его вывод SCK соединён с GND
(тогда ЦАП берёт BCK как системный такт). Поэтому `mclk` из `i2s_audio_out`
в этой плате никуда не выведен.

### 4. VGA (только выходы, ЦАП строит пользователь)

Сигналы выведены на P2 и не подключены ни к чему на плате.

| Сигнал | Разъём P2 | Пин ПЛИС |
|---|---|---|
| HSYNC | 1 | IO105 |
| VSYNC | 3 | IO103 |
| R[0] (LSB) … R[3] (MSB) | 5, 7, 9, 11 | IO100, IO98, IO85, IO77 |
| G[0] (LSB) … G[3] (MSB) | 13, 17, 2, 4 | IO76, IO32, IO106, IO104 |
| B[0] (LSB) … B[3] (MSB) | 6, 8, 10, 12 | IO101, IO99, IO86, IO83 |
| GND | 21, 22, 23, 24 | — |

`PIN_101` (`VGA_B[0]`) совмещён с конфигурационным выводом `nCEO`.
Если Quartus резервирует его как `~ALTERA_nCEO~`, Fitter выдаёт **Error 176310**.
В `board_specific.qsf` пин освобождён для обычного I/O после конфигурации:

```tcl
set_global_assignment -name CYCLONEII_RESERVE_NCEO_AFTER_CONFIGURATION "USE AS REGULAR IO"
```

Это позволяет сохранить назначение `VGA_B[0]` на `PIN_101` без изменения распиновки.

ЦАП на резисторах (пример R-2R для 4 бит на канал): резисторы 1 кОм и 2 кОм,
на каждый канал 4 разряда; сигналы синхронизации через 330 Ом. Уровни 3.3 В,
VGA-монитор ожидает 0.7 В на канал.
Это сборка пользователя, на плате её нет.

### 5. Универсальные выводы GPIO (разъём P3)

Разъём P3 не занят ничем, кроме питания. Его 24 сигнальных пина доступны
как `GPIO[23:0]` (порядок по номеру пина: `GPIO[0]` = IO110 … `GPIO[23]` = IO144).

Таблица соответствия контактов P3:

| P3 (левый, нечётный) | IO | | P3 (правый, чётный) | IO |
|---|---|---|---|---|
| 9 | 143 | | 10 | 144 |
| 11 | 141 | | 12 | 142 |
| 13 | 137 | | 14 | 138 |
| 15 | 135 | | 16 | 136 |
| 17 | 132 | | 18 | 133 |
| 19 | 128 | | 20 | 129 |
| 21 | 126 | | 22 | 127 |
| 23 | 124 | | 24 | 125 |
| 25 | 120 | | 26 | 121 |
| 27 | 115 | | 28 | 119 |
| 29 | 112 | | 30 | 113 |
| 31 | 110 | | 32 | 111 |

Контакты P3: 33, 34 — 5 В; 37, 38 — 3V3; 41, 42 — 2V5; 43–46 — GND.

Свободные пины P2 и P4 (не подключённые к периферии выше): P2 контакты 16 (IO31) и
18 (IO33); P4 — IO49, IO51, IO53, IO55, IO59, IO64, IO66, IO68, IO70, IO72, IO52,
IO54, IO58, IO60, IO65, IO67, IO69, IO71 (см. `board_specific.qsf`).
Эти пины можно добавить в QSF при необходимости.

## Сборка и прошивка

Выбор платы — стандартным скриптом:

```bash
cd ./labs/1_basics/1_01_and_or_not_xor_de_morgan/
./06_choose_another_fpga_board.bash      # выбрать picburner_ep4ce6
./03_synthesize_for_fpga.bash
```

Лабораторные работы выбирают периферию через `lab_specific_board_config.svh`
(определения `INSTANTIATE_*`), как и на других платах. Плата рассчитана на
работы без VGA и на работы с TM1638, микрофоном и ЦАП. Полный перебор всех
лабораторий на реальной плате пока не выполнен.

## Ограничения

* VGA: выходы выведены, ЦАП и монитор — задача пользователя.
* Светодиоды активные низкие (логика инвертирована в `board_specific_top.sv`).
* Нет 7-сегментного индикатора на плате: индикация через TM1638.
* Quartus-сборка на этой плате проверена только синтаксически (верхний модуль
  компилируется с модулями периферии). Полную сборку и прошивку ещё нужно
  проверить на реальной плате.
